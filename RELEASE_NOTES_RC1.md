# Flute 1.0.0-rc.1

Flute is an offline Android music player built with Flutter.

## Features

- Local music-library scanning
- Play, pause, seek, previous, and next controls
- Queue management
- Shuffle and repeat modes
- Favorites and recently played history
- Background audio playback
- Lock-screen and notification controls
- Bluetooth and wired-headset controls
- Android home-screen playback widget
- Light, dark, and system themes

## Release status

This is a release candidate intended for public testing. Online music search and streaming are not included in this release.
